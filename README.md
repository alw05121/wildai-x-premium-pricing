## 付款之前先确认自己有没有资格

不是有卡就能买。X 对订阅账号有两个硬性门槛：

1. 账号注册时间满 90 天；
2. 绑定了已验证的手机号。

2025 年 4 月 1 日起，X 取消了此前保留的传统免费蓝 V 认证，付费订阅成了拿到蓝勾的唯一途径。这意味着账号年龄不够、手机号没验证，付款按钮你可能都点不到。

流程本身不复杂：注册账号 → 选择需要的服务 → 回到 X 的订阅页面，复制当前页面上的登录状态信息 → 粘贴回平台并确认账号邮箱 → 扫码支付。平台拿到信息后，代你用官方渠道完成订阅，之后的续订也由平台处理。

## 几个买之前常问的问题

**蓝勾会不会掉？** 只要订阅持续有效就不会。掉标一般是订阅到期或扣款失败，App 内购和网页端都一样。

**先买 Basic 再升级行不行？** 可以，三档之间随时切换，变更在下一个计费周期生效。但如果你想的是「先用 Basic 试试，反正有编辑功能」，那蓝勾不会提前出现。

**年付一定划算吗？** 官方年付确实比月付省将近一个月，但前提是你确定会用满一年。如果只是短期需要蓝标做个认证，月付先跑一轮更稳妥。

**代付会被封号吗？** 平台方声称走的是官方订阅渠道，第三方评测也提到关键在于账号本身要干净——注册时 IP 环境混乱、有异常记录的账号，用什么方式都可能出问题。这一点没有公开的官方结论可以核对，属于需要自己权衡的部分。
